A one-line joke about working beside AI coding agents, written by a small deterministic Python program for make.fun's "The joke the reviewer laughs at" bounty. The joke plays on the most recognisable moment in an agent-assisted review: you ask for a one-line fix, the agent rewrites half the file, and the one line it leaves alone is the line with the bug.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The text is a single line of 1–280 characters, no network, no randomness, no dependencies — just Python 3.13 and the standard library.
